# Security policy

## Scope and safe use

This project is a local, read-only static checker. It does not make network requests, execute scanned code, exploit targets, or provide malware-detection guarantees. Use it only on source you own or are explicitly authorized to review.

## Reporting a vulnerability in this project

Please do not publish secrets, personal data, or exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository if enabled; otherwise contact the maintainers privately through their GitHub profile and request a coordinated disclosure channel. Include the affected commit/version, impact, minimal reproduction using a local test fixture, and a suggested fix. Allow maintainers reasonable time to investigate before public disclosure.

Findings from the heuristic scanner are not automatically confirmed vulnerabilities. Include human validation and avoid testing on third-party systems.
